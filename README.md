# ЛР 5, Варіант №15

Обчислення: `A1, A2, A3, A4, B, C, D`.
Повільні: `A1`, `A2` (по 7 с). Решта швидкі (по 1 с).
Залежності: `B(A1, A2)`, `D(B)`, `C(A3, A4)`.

Програма запускає `A1` та `A2` паралельно через `std::async(std::launch::async, ...)`, а в головному потоці послідовно виконує `A3`, `A4`, `C`. Після `future.get()` запускаються `B` і `D`. Для виводу без змішування рядків використано `std::osyncstream`.

## Результат

**Мінімальний час ≈ 9 секунд; 3 потоки загалом (головний + 2 додаткові).**

- `A1` і `A2` виконуються одночасно за 7 секунд.
- `A3 → A4 → C` виконуються в головному потоці за 3 секунди паралельно з ними.
- `B → D` потребують ще 2 секунд після `A1` та `A2`.
- Критичний шлях `A1/A2 → B → D` дорівнює 7 + 1 + 1 = **9 с**.
- Сумарна тривалість усіх робіт становить 19 потокосекунд. Двом потокам потрібно щонайменше 19/2 = 9,5 с, тому 9 секунд з двома потоками неможливі.

## Збирання і запуск

Потрібен компілятор із підтримкою C++20, зокрема `<syncstream>` (`g++ 11+` або актуальний MSVC). В Apple Clang `<syncstream>` може бути недоступним: тоді використай Homebrew GCC.

### Linux / macOS (GCC)

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build
./build/prog
```

### Windows (MSYS2 MinGW-w64 або MSVC)

```powershell
cmake -S . -B build
cmake --build build --config Release
```

В MSYS2 MinGW:

```powershell
./build/prog.exe
```

У Visual Studio з багатоконфігураційним генератором:

```powershell
./build/Release/prog.exe
```

Програма виводить повідомлення про завершення кожної дії, час у секундах і `Work is done!`. Порядок повідомлень для паралельних дій може відрізнятися.
